Data

Unravel reads the code you open on your computer and keeps what it found there, in its cache folder. It sends nothing anywhere. To read a project it runs programs already on your computer: cmake for a compilation database, git for the history and python3 for Python files. This website loads no fonts or scripts from third parties; to show the newest version it asks GitHub's public API.
